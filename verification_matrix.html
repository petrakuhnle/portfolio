05 · Key design decisions

One question guided the design: which role needs which view and filter? Engineers filter by method, decision makers by status. The same thread runs through Use Case 3, Review Center.

06 · Lessons learned

The prototype did more than show the design. It drove the discovery.

01
Prototype as discovery toolA detailed prototype raises the questions that define the MVP. What if one method is still open? Who was assigned, and how do I reach them? A small system that ships is worth more than a complete one in Figma.
02
Ask instead of assumeI was new to the domain, so I asked instead of assumed. Experts designing their own tools carry their own bias and rarely question a senior engineer or a client.
03
Generated prototypes still need usersAI tools know job roles in general, never one company's specifics. Generated prototypes still go in front of real users.
